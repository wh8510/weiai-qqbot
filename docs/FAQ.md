# FAQ / 排错

## 机器人完全不回复

按顺序查：

1. **名单**：私聊白名单 / 群白名单是否为空？空 = 默认拒绝。
2. **群模式**：新群默认 `mention_only`，只有 @ 或叫名字才回。
3. **Provider**：是否启用？API Key 是否配置？`chat` 角色是否绑定？
4. **OneBot**：总览页是否显示已连接？最近事件时间？
5. **token**：NapCat 的 access token 与 `.env` 是否一致？
6. **路径**：反向 WS 是否是 `/onebot/v11/ws`？NapCat 配的是“客户端”还是“服务端”？
7. **日志**：控制台是否有 `模型调用失败` / `消息被名单拒绝`。

## 群里 @ 了也不回

- 群是否在白名单？
- 群成员是否在黑名单？
- 群模式是否 `off`？
- 是否超过每小时/每日上限？
- 是否在静默时段（只影响主动，不影响 @ 回复）？
- 模型是否返回了 `silent`？看「会话 → 消息」或日志。

## 它说“看不到图”

- 主模型不支持视觉（例如 DeepSeek V4 Pro），且没有绑定视觉角色。
- 去「模型与密钥」确认 `chat` 模型能力徽章；或把 `vision` 角色绑定到 DeepSeek Flash / Gemini / Qwen-VL 等支持图片的模型。
- 点模型「探测」，确认视觉通过。
- 这是**预期行为**：不支持时按人格承认，不假装看过。

## 图片/表情包发不出去

- 表情包库是否为空？在「媒体库」上传；如果上传接口不可用，也可以把图片放进 `data/stickers/`，再用管理端/数据库补记录。
- QQ 图片消息段需要 NapCat 支持 `image`；真实联调时确认。
- 文件太大 / 路径不存在会失败，看 outbox 错误。

## 语音不工作

- 只有 **Windows** 有本地 TTS；Linux 显示不可用是设计如此。
- Windows 是否安装了中文语音？`System.Speech` 可能只有英文音色。
- QQ 语音需要 silk；程序会本地转码，但仍需真实 NapCat 验证。
- 语音失败会自动回退成文字，不会丢消息。

## 花了太多钱

- 看「用量与预算」按用途/模型/会话拆分。
- 降低 `chat` 模型价格档位；记忆/分类换更便宜的模型。
- 调低主动频率、群聊概率、每日上限。
- 关掉群聊 `smart/active`，改 `mention_only`。
- 预算上限是硬闸：到线会停主动/降级，不会无限烧。

## 模型测试返回 401 / API Key 无效

先看「模型与密钥」Provider 卡片上的 **Key 尾号**，和你复制的 Key 最后 4 位对比。

- 点「配置 Key」会显示「尾号 / 长度」；需要核对完整 Key 时点「显示」（会写入审计日志）。
- 如果尾号不对：说明保存的不是你以为的那把 Key，重新粘贴并保存。
- 如果 Key 中间有空格/换行，或者粘贴时带上了别的后缀，服务端现在会只取第一个词，并显示尾号；仍建议重新复制一次。
- 如果尾号对但仍 401：确认 **Base URL** 和 Key 是同一家厂商的（DeepSeek 的 Key 不能填到 OpenAI/中转的 Base URL）。
- DeepSeek 的 Key 通常是 `sk-` 开头、约 35 位；不要带 `Bearer ` 前缀。
- 测试按钮会依次探测文本 / JSON / 视觉；只要文本 401，就是 Key 或 Base URL 问题，不是模型目录问题。

## 忘记管理员密码

```bash
node dist/server/cli.js reset-password
```

会生成新密码并要求下次登录修改。

## 主密钥丢了

加密字段不可恢复。只能：

- 从备份恢复 `master.key` + 数据库；
- 或者删库重来（会丢失消息/记忆/Key）。

请现在就备份 `data/master.key`。

## 数据库能直接打开吗？

可以打开 SQLite 文件，但消息正文、发送者名、摘要、事实、日记、outbox/jobs、API Key 都是密文。元数据（时间、QQ 号、表结构）仍可见。详见 [SECURITY.md](SECURITY.md)。

## 能同时接多个 QQ 吗？

v1 单账号。表结构预留了 `account_id`，后续可扩展。现在跑两个实例需要两份 data 目录和两个端口。

## 能接 Discord / Telegram 吗？

v1 只实现 OneBot 11。协议层是薄的，但 v1 不承诺其他平台。

## 模型列表过期了

改 `catalog/providers.yaml` 或在管理端「模型与密钥 → 添加模型」，不需要改代码。模型目录是数据，不是业务逻辑。

## 端口/反代

默认只监听 `127.0.0.1:8080`。云端用 Caddy/Nginx 反代到 8080；NapCat 反向 WS 用 `wss://域名/onebot/v11/ws`。不要直接把 8080 暴露公网。
