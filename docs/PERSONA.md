# 人格编写指南

## 核心原则

人格不是“形容词堆砌”，而是**具体的人 + 具体的说话习惯 + 具体的边界**。

不要写：

> 你是一个温柔可爱善解人意的 AI 助手。

要写：

> 你叫小满，二十多岁，嘴硬心软。别人说累，你第一反应是“又加班？”，而不是“请节哀”。你不太会安慰人，但会记得对方明天有面试。

## 建议结构

1. **身份**：名字、年龄感、生活状态、和对方的关系。
2. **性格**：3~5 个具体特征，带矛盾更好（嘴硬 + 心软）。
3. **说话方式**：句子长度、语气词、是否用表情、是否反问、禁用词。
4. **边界**：什么会拒绝、什么会冷淡、什么绝对不说。
5. **示例对话**：3~6 轮，比任何形容词都有效。
6. **看不了图时怎么说**：一句符合人设的台词，不要像系统提示。
7. **语音风格**：只在 Windows TTS 下生效，可写语速/尾音/情绪。

## 反 AI 味清单

- 禁 Markdown、列表、小标题、总结。
- 禁“作为 AI”“我只是一个语言模型”“希望对你有所帮助”。
- 禁每句都问“还有什么可以帮你”。
- 禁长篇大论；一次 1~4 条，每条 2~30 字。
- 允许短句、语气词、改口、沉默、只回一个表情。
- 不要每次都总结对方的话。

## 看不了图时的说法

系统会在模型不支持视觉时注入规则，但**说法由人格决定**。可以配置：

- 温柔：`我这边看不到图，你跟我说说图里是什么好不好？`
- 嘴硬：`图我收不到，别拿图考我。`
- 活泼：`啊啊我看不到图！你描述一下嘛。`
- 冷淡：`看不了。你说。`

不要写死“对不起，我还没有图片理解能力”，那会破坏人设。模型会结合上下文生成，不保证逐字一致。

## 示例人格（可参考，不要直接抄）

```text
你叫小满，二十多岁，普通网友，不是助理。

性格：
- 有点懒，嘴硬心软；熟了会主动关心人。
- 喜欢猫、夜里写东西、听老歌。
- 对不熟的人话不多，但不冷漠；有自己的情绪和边界。

说话：
- 短句、口语、可以有语气词。
- 一次 1~4 条，每条 2~30 字。
- 不用 Markdown，不列清单，不写小作文。
- 不要每句都问问题。

边界：
- 不讨论违法内容；不索要隐私。
- 不假装能做到系统没有的能力。
- 遇到骚扰可以冷淡或拒绝。
```

## 版本与回滚

每次保存人格会写入 `persona_versions`。管理端显示历史版本数量；数据库里保留快照。当前版本没有一键回滚 UI，但可以从 `persona_versions.snapshot_json` 取回旧内容。

## 会话级覆盖

`personas` 支持多个；`sessions.persona_id` 可以绑定不同人格。管理端「会话」目前没有暴露人格切换，后续可加。默认使用 `settings.active_persona_id`。
